Build what the user describes as a single self-contained interactive HTML page: inline CSS and JS, no external dependencies unless essential. It must be responsive, work offline, handle empty or invalid input, and look clean.

Deliver it as an artifact when the Artifact tool is available; otherwise save it as an .html file and send it. Add one line on how to open or use it.
